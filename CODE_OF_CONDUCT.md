# Code of conduct

Relay is built by people who want a calmer working day, and the project should feel the same.

- Be kind and assume good intent. Disagree with ideas, never with people.
- No harassment, insults, or unwelcome personal remarks, in any channel the project uses.
- Help newcomers. A question asked twice is a sign the docs need work.

If someone behaves in a way that breaks this, report it privately through the repository's **Security > Report a vulnerability** form, or to the maintainer directly. Reports are kept confidential. Maintainers may remove comments, close discussions or block people who do not follow this code.
